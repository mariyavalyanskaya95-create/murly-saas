# Як писати тренажер граматики Murly (100 завдань)

Тип даних: `lib/drills/types.ts` (прочитай). Один файл на тему: `lib/drills/<slug>.ts`:

```ts
import type { Drill } from './types';
export const DRILL: Drill = { slug: '...', ... };
```

## Для кого
Підлітки 12-17 і дорослі, рівень A1-B1 (вказаний у завданні). Ідея як у квізі Марії «Past Simple + 3 форми дієслів, ~100 завдань»: спочатку коротка теорія, потім багато практики з поясненням кожної відповіді.

## Теорія (theory)
- when: 3-5 випадків «коли вживаємо», кожен з прикладом англійською і перекладом українською.
- forms: рядки + / − / ? (sign: '+', '−', '?'), формула простими словами і приклад. Можна додати рядок «коротка відповідь» тощо.
- trap: 1-3 головні пастки для українськомовних учнів (title, text пояснення, wrong речення з помилкою, right правильне).
- markers: 6-12 слів-маркерів (якщо для теми нема маркерів, дай корисні слова-підказки).
- extra (якщо доречно): окремий блок. Для Past Simple обов’язково «Про 3 форми дієслів»: V1 / V2 / V3, правильні (-ed, правила написання) і неправильні, таблиця rows з 10-15 частих дієслів [V1, V2, V3, переклад]. Для інших тем: наприклад таблиця скорочень, правила написання -ing, a / an тощо.

## Раунди (rounds): рівно 5 по 20 завдань = 100
1. «Форми» (базова механіка, найпростіше).
2. «Заперечення і питання».
3. «Коли вживати» (вибір за змістом і маркерами).
4. «Пастки» (типові помилки, «знайди правильне речення», схожі форми).
5. «Фінальний бос» (змішано, складніше, міні-ситуації з 2 речень).
Назви раундів українською, коротко, можна з гумором (напр. «Раунд 5. Фінальний бос»).

## Завдання
- Приблизно 60-70% `choice` (3-4 варіанти, a = індекс правильного, правильний став у різні позиції, не завжди 0) і 30-40% `type` (учень вписує сам).
- `choice`: q з одним `___`. Для «яке речення правильне?» q = 'Обери правильне речення.' і варіанти цілими реченнями (до 60 символів).
- `type`: q з одним `___` і підказкою в дужках одразу після нього: `'Yesterday we ___ (watch) a film.'`. answers: усі правильні варіанти, включно зі скороченою і повною формою (`["didn’t go", "did not go"]`). Відповідь однозначна, без варіантів, які теж були б правильні, але їх нема в answers.
- why: 1-2 речення українською, «Чому так?»: правило + чому інші не підходять. Без води.
- Речення з життя підлітків і дорослих: школа, друзі, хобі, спорт, музика, фільми, ігри, їжа, подорожі, тварини, котики, телефон, робота. Різні імена (Олена, Макс, Sophie, Tom, Dan, Ira...).
- Жодних повторів речень у межах тренажера. Варіанти в choice правдоподібні (типові помилки), а не абсурдні.
- Перевір кожну відповідь двічі: граматика має бути бездоганною (британська або американська, але послідовно), один пропуск = одна правильна відповідь.

## Правила стилю
- Інструкції, теорія, why: українською. Речення завдань: англійською.
- БЕЗ довгих тире (— і –), використовуй двокрапку, кому або дефіс-мінус у формулах ('−' для знака заперечення в sign дозволено). Без емодзі. Апостроф ’ в українському тексті; в англійських реченнях використовуй ’ (typographic) і послідовно.
- Жодної військової тематики, політики, війни, армії. Не копіюй приклади з підручників (Murphy тощо): усе своє.
- Строки в TS: одинарні лапки; якщо всередині є ' використовуй ’ або подвійні лапки.

## Перевірка (обов’язково)
Створи тимчасовий файл у корені проєкту і запусти:
```
cd /sessions/wonderful-brave-ride/murly-saas && cat > _chk.ts <<'EOF'
import { DRILL } from './lib/drills/<slug>';
const qs = DRILL.rounds.flatMap(r => r.questions);
console.log(DRILL.rounds.length, DRILL.rounds.map(r => r.questions.length).join(','), qs.length);
const bad = qs.filter(q => (q.q.match(/___/g) || []).length > 1 || (q.k === 'type' && (q.q.match(/___/g) || []).length !== 1) || (q.k === 'choice' && (q.a < 0 || q.a >= q.options.length)));
console.log('bad', bad.length, bad.map(b => b.q));
const dup = qs.map(q => q.q).filter((q, i, a) => a.indexOf(q) !== i); console.log('dup', dup);
EOF
npx -y tsx _chk.ts; rm _chk.ts; grep -c '[—–]' lib/drills/<slug>.ts
```
Має бути: 5 раундів, 20,20,20,20,20, 100, bad 0, dup [], 0 довгих тире. Також `npx tsc --noEmit -p .` не має давати помилок у твоєму файлі.
