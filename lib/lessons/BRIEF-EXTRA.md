# Як подовжити готовий урок Murly (для помічника)

Власниця каже, що готові уроки «дрібні». Завдання: у кожен урок свого файлу додати ще ~20-25 завдань автоперевірки і розширити домашку. Старі блоки НЕ змінюй і НЕ видаляй.

Формат блоків: `lib/lesson.ts`, хелпери `lib/lessons/helpers.ts`, синтаксис вправ `lib/exercise.ts` (gap: `[відповідь]`, кілька через /; choice: `{правильний|хибний|хибний}` перший правильний; truefalse: `твердження = True/False`; match: `ліво = право`; sort: `Група: фраза, фраза` по рядку на групу; translate: `українське = English / English`; open: просто рядки).

## Важливо про id блоків
Не використовуй існуючі h/ex/... з файлу для нових блоків (вони рахують id по порядку, і вставка зсуне id старих блоків). На початку файлу після існуючого `const { ... } = makeHelpers('bN')` додай другий набір з іншим префіксом, напр.:
`const X = makeHelpers('bNx');` і для нових блоків пиши `X.h(...)`, `X.ex(...)`, `X.note(...)`, `X.game(...)`.
(у lib/practice.ts: `import { makeHelpers } from './lessons/helpers'; const X = makeHelpers('prx');`)

## Що додати в кожен урок
1. Перед блоком Homework (заголовок з «Homework») вставити:
   - `X.h('Extra practice · якщо лишився час або на наступний урок')`
   - `X.ex(...)` з 3 секціями різних типів (напр. gap + choice + translate або match), по 6-8 завдань у секції. Лексика і граматика саме цього уроку (слова з його vocab, правило з його tip), ситуації з теми уроку.
   - `X.game('...', '...', '...')` гра на 8-10 пар (q = a), напр. слово = переклад або початок фрази = кінець.
   - `X.note('...')` для вчителя: як використати, відповіді до неочевидних місць.
2. Наприкінці уроку (після останнього блоку Homework) додати `X.ex(...)` «Homework plus» з 2 секціями (gap/choice/translate по 6-8 завдань) + 1 секція open на 2-3 питання письма за темою.
Разом +20-30 завдань на урок. Рівень і вік як у самого уроку (kids 6-11: дуже прості речення A1, коротко; teens; adults B1-C1 відповідно). Для уроків формату НМТ (id з nmt): завдання у форматі НМТ (choice з 4 варіантами, cloze), рівень B1.
Для коротких уроків Listening/Reading у lib/practice.ts: додай у кінець кожного: `X.h('More practice')`, `X.vocab(...)` 8-10 слів з тексту, `X.ex(...)` 2-3 секції (по 6-8 завдань: питання до тексту truefalse/choice, слова gap/match, translate) і `X.talk(...)` 4-5 питань для обговорення. Разом +18-25 завдань.

## Переклади (обов’язково)
Сайт показує уроки українською, російською й англійською: кожен новий УКРАЇНСЬКИЙ рядок (інструкції секцій, тексти note, h, назви і prompt ігор, українські слова у vocab, match і translate, українські частини завдань) треба перекласти. Збери їх у файли:
- `lib/content/ru/extra-<твоя-назва>.json`: { "український рядок": "русский перевод" }
- `lib/content/en/extra-<твоя-назва>.json`: { "український рядок": "English translation" }
Ключ має збігатися з рядком у даних ДОСЛІВНО (після trim, як він потрапить у блок). Для vocab ключ: саме українська частина після «=». Для translate-завдання ключ: prompt (до «=»). Для інструкцій: текст інструкції. Англійські речення не перекладай.
Найпростіше: після правок запусти скрипт, який імпортує LIBRARY з lib/library.ts, знаходить у твоїх нових блоках (id з твоїм префіксом) усі рядки з кирилицею (рекурсивно по всіх полях, а для exercise по instruction, prompt і parts[].v), і перевір, що кожен є ключем в обох JSON.

## Правила
- Українською інструкції, note. Англійською речення вправ.
- БЕЗ довгих тире (— і –). Без емодзі. Апостроф ’.
- Жодної військової тематики, політики. Не копіюй з підручників.
- Відповіді однозначні й граматично правильні.
