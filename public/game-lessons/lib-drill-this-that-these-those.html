1Теорія practiceteacher + student

Коли вживаємо

this: одна річ поруч, тут: This bag is really heavy. (Ця сумка дуже важка.)

these: кілька речей поруч: These cookies are still warm. (Ці печеньки ще теплі.)

that: одна річ далеко, там: Look at that bird on the fence! (Подивись на ту пташку на паркані!)

those: кілька речей далеко: Those boys are from my class. (Ті хлопці з мого класу.)

one / ones замість іменника, щоб не повторювати: I don’t like the red T-shirt. I prefer the blue one. (Мені не подобається червона футболка. Мені більше подобається синя.)

Форми

поруч this + однина, these + множина. Приклад: this book, these books

далеко that + однина, those + множина. Приклад: that house, those houses

+ This is ... / These are ... ; That is (That’s) ... / Those are .... Приклад: This is my friend Lily.

? Is this / Is that ...? Are these / Are those ...? У відповіді it або they: Yes, it is. / No, they aren’t.. Приклад: Are those your keys? Yes, they are.

one one замість іменника в однині, ones у множині: the red one, the big ones, a new one. Приклад: Which bike is yours? The green one.

телефон Про себе кажемо This is ...: This is Dan.. Приклад: Hi, Kate, this is Max.

Головна пастка

this і that тільки з одниною. Якщо іменник у множині (shoes, jeans, kids), потрібне these або those, і дієслово are.

✗ This shoes are too small.

✓ These shoes are too small.

У короткій відповіді it і they. На питання з this / that відповідаємо через it, з these / those через they.

✗ Is this your phone? Yes, this is.

✓ Is this your phone? Yes, it is.

one чи ones. one замінює один предмет, ones замінює кілька. Дивимося, яким був іменник: jeans (множина) → ones.

✗ I like the black jeans, not the blue one.

✓ I like the black jeans, not the blue ones.

Маркери: here → this / these, there, over there → that / those, in my hand → this, in the sky, across the street → that / those, this morning, this week, that day, that summer, Which one? / Which ones?, the red one / the red ones, a new one

Шпаргалка: близько чи далеко

Близько до мене: this і these. Далеко від мене: that і those. Те, що вже минуло або що хтось щойно сказав, теж часто that: That was a great film! That’s a good idea. One і ones ставимо після прикметника або this / that, щоб не повторювати іменник.

де? · однина · множина

поруч (here) · this · these

далеко (there) · that · those

замість іменника · one · ones

приклад · this cake, the big one · those cakes, the small ones
