1Теорія practiceteacher + student

Коли вживаємо

Звички й стани в минулому, яких тепер немає: used to + V: I used to play the violin. (Колись я грав на скрипці (а тепер ні).)

Те, що змінилося: there used to be: There used to be a cinema here. (Колись тут був кінотеатр.)

Повторювані дії в минулому: would + V (тільки дії, не стани): Every summer Grandma would bake cherry pies. (Щоліта бабуся пекла пироги з вишнями.)

Ти вже звик: be used to + іменник / V-ing: Lily is used to getting up early. (Лілі звикла рано вставати.)

Процес звикання: get used to + іменник / V-ing: Max is getting used to his new school. (Макс звикає до нової школи.)

Форми

+ used to + V1 (однаково для всіх осіб). Приклад: We used to live in Brighton.

− didn’t use to + V1 (після didn’t без -d). Приклад: Tom didn’t use to like cats.

? Did + підмет + use to + V1?. Приклад: Did you use to wear glasses?

would would (’d) + V1: тільки дії, що повторювалися в минулому. Приклад: On Sundays we would go fishing.

be used to am / is / are (was / were) used to + іменник або V-ing. Приклад: I’m used to the noise. She isn’t used to driving.

get used to get / got / will get used to + іменник або V-ing. Приклад: Don’t worry, you’ll get used to it.

Головна пастка

didn’t use to, а не didn’t used to. Після did / didn’t дієслово в базовій формі, тому use без -d. У ствердженні пишемо used to.

✗ I didn’t used to like tea.

✓ I didn’t use to like tea.

be used to + V-ing, а не + V1. У be used to і get used to слово to є прийменником, тому після нього іменник або V-ing. Порівняй: I used to get up early (колись вставав) і I’m used to getting up early (звик вставати).

✗ I’m used to get up at six.

✓ I’m used to getting up at six.

would не для станів. would вживаємо тільки з діями, що повторювалися. Для станів (be, have, live, like, know) підходить лише used to.

✗ When I was little, we would live in a small flat.

✓ When I was little, we used to live in a small flat.

Маркери: when I was a kid, when I was little, years ago, in the past, any more / anymore, no longer, every summer, at first, still, now

Чотири схожі конструкції

used to + V1: колись було, тепер ні. would + V1: повторювалося в минулому. be used to + V-ing: уже звик. get used to + V-ing: звикаю або звикну. Для звичок у теперішньому used to не вживаємо: кажемо usually + Present Simple.

used to + V1 · I used to swim every day. · колись я щодня плавав (тепер ні)

didn’t use to + V1 · She didn’t use to eat fish. · раніше вона не їла рибу

would + V1 · We would play outside till dark. · ми, бувало, гралися надворі до темряви

be used to + V-ing · I’m used to working late. · я звик працювати допізна

get used to + V-ing · I’m getting used to working late. · я звикаю працювати допізна

get used to + іменник · You’ll get used to the cold. · ти звикнеш до холоду

usually + V1 (зараз) · I usually walk to school. · зазвичай я ходжу до школи пішки
