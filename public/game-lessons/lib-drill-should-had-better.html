1Теорія practiceteacher + student

Коли вживаємо

Порада і думка: should / shouldn’t: You should try the new pizza place. (Тобі варто спробувати нову піцерію.)

Те саме, трохи серйозніше: ought to: We ought to tell the teacher. (Нам слід сказати вчителеві.)

Сильна порада «а то буде погано»: had better (’d better): You’d better leave now, or you’ll miss the train. (Краще виходь зараз, а то спізнишся на потяг.)

Жаль або докір про минуле: should have + V3: I should have saved my work. (Треба було зберегти роботу.)

Не треба було: shouldn’t have + V3: You shouldn’t have eaten so much cake. (Не треба було тобі їсти стільки торта.)

Форми

+ should + V; ought to + V; had better (’d better) + V без to. Приклад: You should rest. You ought to rest. You’d better rest.

− shouldn’t + V; ought not to + V; had better not + V. Приклад: You shouldn’t worry. You’d better not be late.

? Should + підмет + V? What / Where should ...?. Приклад: Should I call her? What should we bring?

минуле should have / shouldn’t have / ought to have + V3: треба було або не треба було. Приклад: We should have booked earlier.

Головна пастка

had better to і hadn’t better. Після had better дієслово без to. Заперечення: had better not, а не hadn’t better.

✗ You hadn’t better to be late.

✓ You’d better not be late.

had better не про минуле. Хоч тут і є had, had better говорить про зараз або майбутнє. Щоб пожалкувати про минуле, беремо should have + V3.

✗ Yesterday I had better study more.

✓ Yesterday I should have studied more.

should to і ought без to. should завжди без to, а ought завжди з to.

✗ You should to call him. You ought call him.

✓ You should call him. You ought to call him.

Маркери: порада → should, I think you should ..., I don’t think you should ..., If I were you, I’d ..., or / otherwise → had better, жаль про минуле → should have, yesterday / last night + should have

Шпаргалка: порада, попередження, жаль

had better майже завжди скорочуємо: I’d, you’d, we’d better. Таблиця: форма, значення, приклад.

should · порада, думка · You should read more.

ought to · порада, «так правильно» · You ought to apologise.

had better (’d better) · сильна порада, попередження · You’d better hurry.

had better not · краще не роби, бо буде погано · You’d better not tell Mum.

should have + V3 · треба було (а не зробили) · I should have called.

shouldn’t have + V3 · не треба було (а зробили) · He shouldn’t have shouted.

Тренажер на 100 завдань: 5 раундів по 20. На уроці можна пройти 1-2 раунди, решту задати додому. Пояснення до кожної відповіді учень бачить у тренажері на сайті (розділ «Граматика»).
