1Теорія practiceteacher + student

Коли вживаємо

Третій тип: уявне минуле, якого насправді не було: If I had left earlier, I would have caught the bus. (Якби я вийшов раніше, я встиг би на автобус.)

Жаль або докір за минуле: If you had told me, I would have helped. (Якби ти мені сказав, я б допоміг.)

Можливий результат у минулому: could have / might have: If we had booked earlier, we might have got better seats. (Якби ми забронювали раніше, можливо, отримали б кращі місця.)

Змішаний тип: минула умова, результат зараз: If I had slept more, I wouldn’t be so tired now. (Якби я більше спав, зараз не був би такий втомлений.)

Змішаний тип: постійна умова зараз, результат у минулому: If Max weren’t so shy, he would have spoken to her at the party. (Якби Макс не був такий сором’язливий, він заговорив би з нею на вечірці.)

Форми

3 If + had + V3, would have + V3. Обидві частини про минуле.. Приклад: If Lily had trained more, she would have won.

− Заперечення: hadn’t + V3 у частині з if, wouldn’t have + V3 у головній.. Приклад: If it hadn’t rained, we wouldn’t have stayed at home.

? Питання в головній частині: What would you have done if ...?. Приклад: What would you have done if you had lost your bag?

мікс 1 Минуле → зараз: If + had + V3, would + V (часто з now, today, still).. Приклад: If I had saved money, I would have a new bike now.

мікс 2 Зараз завжди → минуле: If + Past Simple, would have + V3.. Приклад: If Dan weren’t afraid of dogs, he would have stroked the puppy.

’d Скорочення ’d буває і had, і would. If I’d known, I’d have come = If I had known, I would have come.. Приклад: If she’d asked, I’d have said yes.

Головна пастка

Ніякого would після if. Українське «якби я знав» не перекладаємо як If I would have known. Після if стоїть had + V3, а would have живе тільки в головній частині.

✗ If I would have known, I would have come.

✓ If I had known, I would have come.

Після have тільки V3. У would have, could have, might have дієслово завжди в третій формі: gone, seen, done. Форма з другої колонки (went, saw) тут помилка. І пишемо have, а не of, хоч на слух вони схожі.

✗ We would have went home.

✓ We would have gone home.

Результат зараз: would + V, а не would have. Якщо наслідок минулої події відчуваємо зараз (now, today, still), у головній частині would + V. Would have + V3 тільки для результату в минулому.

✗ If I had eaten, I wouldn’t have been hungry now.

✓ If I had eaten, I wouldn’t be hungry now.

Маркери: If I had known ..., would have + V3, could have + V3, might have + V3, hadn’t + V3, yesterday, last week, last year, now, today, still (змішаний тип), If I’d ... I’d have ..., but I didn’t / but it wasn’t, If I were you, I would have ...

Шпаргалка: усі типи поруч

Нульовий, перший і другий типи вже знайомі, тут вони лише для порівняння. Головна ознака третього типу: had + V3 після if і would have + V3 у головній частині. Таблиця: тип, частина з if, головна частина, приклад.

0 · Present Simple · Present Simple · If you mix red and yellow, you get orange.

1 · Present Simple · will + V · If it’s windy, I’ll wear a hat.

2 · Past Simple · would + V · If I lived by the sea, I’d swim every day.

3 · had + V3 · would have + V3 · If I had noticed you, I’d have waved.

мікс 1 · had + V3 · would + V · If I had watered the plant, it would be alive now.

мікс 2 · Past Simple · would have + V3 · If I spoke Italian, I’d have chatted with the guide.

V3 · go → gone, see → seen · take → taken, eat → eaten · write → written, forget → forgotten

V3 · buy → bought, get → got · know → known, give → given · come → come, run → run
