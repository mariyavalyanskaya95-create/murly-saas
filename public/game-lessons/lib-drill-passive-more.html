1Теорія practiceteacher + student

Коли вживаємо

Результат до тепер: has / have been + V3: The final score has just been posted online. (Фінальний рахунок щойно виклали онлайн.)

Процес саме зараз або в той момент: is / was being + V3: Sorry, your table is being cleaned. (Вибачте, ваш столик саме прибирають.)

З модальними: can / must / should be + V3: Phones must be switched off during the exam. (Під час іспиту телефони треба вимкнути.)

Розмовний get-пасив: щось сталося, часто несподіване: My bike got stolen last night. (Мій велосипед учора ввечері вкрали.)

Думка багатьох людей: it is said that / he is believed to: The castle is said to be haunted. (Кажуть, що в замку живуть привиди.)

Форми

Perfect has / have / had been + V3. Приклад: All the tickets had been sold before we arrived.

Continuous am / is / are / was / were being + V3. Приклад: The road was being repaired all summer.

Modal can / could / must / should / might + be + V3; про минуле: should / must have been + V3. Приклад: This form should be signed by a parent.

− not ставимо після першого допоміжного: hasn’t been, isn’t being, can’t be. Приклад: The email hasn’t been sent yet.

? перше допоміжне дієслово стає перед підметом. Приклад: Has the winner been chosen?

get get / got + V3: розмовний варіант, часто про несподіване або неприємне. Приклад: Lily got invited to the final.

said It is said / believed / thought that + речення = Підмет + is said / believed / thought + to V (to have V3 про минуле). Приклад: It is believed that he lives in Spain. = He is believed to live in Spain.

Головна пастка

being чи been. being для процесу (Continuous), been для Perfect: is being cleaned (саме прибирають), has been cleaned (уже прибрали).

✗ The room has being cleaned.

✓ The room has been cleaned.

Модальне дієслово + be. Після can / must / should у пасиві обов’язково be + V3: must be done. Без be або з to неправильно.

✗ The homework must done by Monday.

✓ The homework must be done by Monday.

He is said that. Або It is said that he ..., або He is said to .... Змішувати дві конструкції не можна.

✗ He is said that he is rich.

✓ He is said to be rich.

Маркери: already / just / yet + has been V3, at the moment / now + is being V3, when I arrived + was being V3, by the time + had been V3, must / should / can + be V3, should have been V3, by + хто зробив, It is said that ..., is believed to ..., is thought to have ..., got + V3

Шпаргалка: одна дія в різних часах

Беремо дію clean the room (прибирати кімнату) і дивимося, як змінюється be. V3 завжди cleaned. Колонки: час, формула, приклад.

Present Simple · am / is / are + V3 · The room is cleaned every day.

Present Continuous · am / is / are being + V3 · The room is being cleaned now.

Past Simple · was / were + V3 · The room was cleaned yesterday.

Past Continuous · was / were being + V3 · The room was being cleaned when I came.

Present Perfect · has / have been + V3 · The room has just been cleaned.

Past Perfect · had been + V3 · The room had been cleaned before the guests came.

Future · will be + V3 · The room will be cleaned tomorrow.

be going to · am / is / are going to be + V3 · The room is going to be cleaned.

Модальні · can / must / should be + V3 · The room must be cleaned today.

Модальні про минуле · should / must have been + V3 · The room should have been cleaned yesterday.

Тренажер на 100 завдань: 5 раундів по 20. На уроці можна пройти 1-2 раунди, решту задати додому. Пояснення до кожної відповіді учень бачить у тренажері на сайті (розділ «Граматика»).
