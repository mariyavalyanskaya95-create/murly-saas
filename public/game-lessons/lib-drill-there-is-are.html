1Теорія practiceteacher + student

Коли вживаємо

Щось є (існує) у якомусь місці: There is a new café near my school. (Біля моєї школи є нове кафе.)

Скільки чогось є: There are 25 students in our group. (У нашій групі 25 студентів.)

Згадуємо щось уперше: There’s a message for you. It’s from Dan. (Тобі повідомлення. Воно від Дена.)

Питаємо, чи є щось: Is there a pharmacy here? Are there any buses at night? (Тут є аптека? Вночі ходять автобуси?)

Про минуле: there was / there were: There were a lot of people at the concert. (На концерті було багато людей.)

Форми

+ There is (there’s) + a / an + однина або + незлічуване (milk, money). Приклад: There’s a cat on the roof.

+ There are + some / число / a lot of + множина. Приклад: There are some apples in the bag.

− There isn’t a / any ...; There aren’t any .... Приклад: There aren’t any clean cups.

? Is there a / any ...? Are there any ...?. Приклад: Are there any tickets left?

коротка відповідь Yes, there is / are. No, there isn’t / aren’t. У «так» не скорочуємо. Приклад: Is there a lift? No, there isn’t.

how many How many + множина + are there ...?. Приклад: How many rooms are there in your flat?

минуле There was + однина; There were + множина. Приклад: There was a storm last night.

Головна пастка

«У моїй кімнаті є ліжко». Не перекладай порядок слів з української. Англійською починаємо з there is, а місце ставимо в кінець.

✗ In my room is a bed.

✓ There is a bed in my room.

There are, they are, their. There are: є, існують. They are (they’re): вони є. Their: їхній. Звучать схоже, але значать різне.

✗ Their are two dogs in the garden.

✓ There are two dogs in the garden.

There have / There is + множина. Have тут не вживаємо. Is чи are залежить від того, що стоїть після: одне чи кілька.

✗ There have two pizzas in the fridge. There is two pizzas.

✓ There are two pizzas in the fridge.

Маркери: a / an, some, any, a lot of, no, how many, how much, in, on, under, next to, near

a / some / any з there is / there are

У ствердженні: a / an для одного, some для кількох або для незлічуваного. У запереченні й питанні: any. Якщо в реченні вже є no, not не додаємо: There are no chairs. Коли перелічуємо, дієслово узгоджуємо з першим предметом: There is a sofa and two chairs.

· однина · множина · незлічуване

+ · There is a pen. · There are some pens. · There is some water.

− · There isn’t a pen. · There aren’t any pens. · There isn’t any water.

? · Is there a pen? · Are there any pens? · Is there any water?

Тренажер на 100 завдань: 5 раундів по 20. На уроці можна пройти 1-2 раунди, решту задати додому. Пояснення до кожної відповіді учень бачить у тренажері на сайті (розділ «Граматика»).
