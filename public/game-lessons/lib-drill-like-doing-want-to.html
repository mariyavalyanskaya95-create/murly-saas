1Теорія practiceteacher + student

Коли вживаємо

Смаки і почуття: like / love / hate / enjoy + -ing: Lily loves dancing, but she hates waking up early. (Лілі обожнює танцювати, але ненавидить рано прокидатися.)

Закінчили, не проти, терпіти не можу: finish / mind / can’t stand + -ing: Have you finished tidying your room? (Ти вже прибрав у своїй кімнаті?)

Бажання і плани: want / hope / decide / plan + to: We decided to stay at home and watch a film. (Ми вирішили залишитися вдома й подивитися фільм.)

Потреба: need + to: I need to charge my phone. (Мені треба зарядити телефон.)

Ввічливе бажання саме зараз: would like / would love + to: I’d like to order a pizza, please. (Я б хотів замовити піцу, будь ласка.)

Форми

-ing enjoy, finish, mind, can’t stand, keep, like, love, hate + V-ing. Приклад: Max enjoys playing chess.

to want, need, hope, decide, plan, learn, would like, would love + to + V (базова форма). Приклад: Sophie wants to learn Spanish.

− перед першим дієсловом: don’t / doesn’t / didn’t; або not перед to: decided not to go. Приклад: Dan doesn’t enjoy running. We decided not to wait.

? Do you like + V-ing? / Do you want to + V? / Would you like to + V?. Приклад: Would you like to come with us?

кого want / would like + кого + to + V (а не want that ...). Приклад: Mum wants me to call her.

обидва після like / love / hate можна і to: I like swimming = I like to swim. Але після would like тільки to.. Приклад: I like cooking. I’d like to cook dinner tonight.

Головна пастка

enjoy to, finish to. Після enjoy, finish, mind, keep тільки -ing, ніколи to.

✗ I really enjoy to play tennis.

✓ I really enjoy playing tennis.

want go без to. Після want, need, hope, decide обов’язково to, а дієслово після to в базовій формі: без -ing і без -s.

✗ She wants go home.

✓ She wants to go home.

like чи would like. I like swimming: мені подобається плавати взагалі. I’d like to swim: я хочу поплавати зараз (ввічливо). Після would like тільки to + V.

✗ I’d like going to the cinema tonight.

✓ I’d like to go to the cinema tonight.

Маркери: enjoy / finish / mind + -ing, keep / can’t stand + -ing, like / love / hate + -ing (або to), go + -ing: go swimming, go shopping, want / need + to, hope / decide / plan / learn + to, would like / would love + to, want somebody to + V, not to + V

Правила написання -ing

Майже завжди просто додаємо -ing: play → playing. Але є кілька правил. Таблиця: правило, приклад, ще приклади.

більшість дієслів: + -ing · read → reading · play → playing, watch → watching

німа -e в кінці зникає · make → making · write → writing, dance → dancing, ride → riding

ee в кінці і be: нічого не зникає · see → seeing · agree → agreeing, be → being

ie в кінці → y · lie → lying · die → dying, tie → tying

один склад, одна голосна + одна приголосна: приголосна подвоюється · swim → swimming · run → running, sit → sitting, get → getting, shop → shopping

наголос на останньому складі: теж подвоюємо · begin → beginning · forget → forgetting, prefer → preferring

наголос не на останньому складі: не подвоюємо · visit → visiting · open → opening, listen → listening

w, x, y в кінці ніколи не подвоюються · fix → fixing · snow → snowing, enjoy → enjoying

l після однієї голосної: у британському варіанті подвоюється · travel → travelling · cancel → cancelling (в американському traveling, canceling)

Тренажер на 100 завдань: 5 раундів по 20. На уроці можна пройти 1-2 раунди, решту задати додому. Пояснення до кожної відповіді учень бачить у тренажері на сайті (розділ «Граматика»).
