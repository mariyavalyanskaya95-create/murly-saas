1Теорія practiceteacher + student

Коли вживаємо

Коротка відповідь на питання: Yes, I do / No, she isn’t: “Do you have a pet?” “Yes, I do.” («У тебе є домашня тварина?» «Так, є.»)

Я теж (на стверджувальне речення): So + допоміжне + I: “I love pizza.” “So do I!” («Я обожнюю піцу.» «Я теж!»)

Я теж ні (на заперечне речення): Neither + допоміжне + I: “I can’t dance.” “Neither can I.” («Я не вмію танцювати.» «Я теж не вмію.»)

Незгода: «А я ні» / «А я так»: “I don’t like horror films.” “Oh, I do!” («Я не люблю фільми жахів.» «А я люблю!»)

Відповідь-думка: I think so / I hope not: “Will it rain tomorrow?” “I hope not.” («Завтра буде дощ?» «Сподіваюся, що ні.»)

Форми

+ Yes, + займенник + допоміжне (do / does / did / am / is / are / was / have / can / will). Без скорочень.. Приклад: Yes, I am. Yes, she has.

− No, + займенник + допоміжне з n’t. Приклад: No, he doesn’t. No, we weren’t.

so So + допоміжне + підмет. Допоміжне те саме, що в першому реченні; якщо його немає, беремо do / does / did.. Приклад: “I’m tired.” “So am I.” “Tom plays chess.” “So does Max.”

neither Neither (або Nor) + допоміжне без not + підмет. Приклад: “I didn’t sleep well.” “Neither did I.”

розмовне Me too = So do I; Me neither = Neither do I. Приклад: “I don’t eat meat.” “Me neither.”

думка I think so / I don’t think so / I hope so / I hope not / I’m afraid so / I’m afraid not. Приклад: “Is the shop open?” “I don’t think so.”

Головна пастка

Yes, I’m. У короткій стверджувальній відповіді не скорочуємо: Yes, I am, Yes, it is, Yes, we have. Скорочення можливе тільки в запереченні: No, I’m not, No, it isn’t.

✗ “Are you ready?” “Yes, I’m.”

✓ “Are you ready?” “Yes, I am.”

Neither I can і неправильний час. Після so / neither порядок як у питанні: спочатку допоміжне, потім підмет. І допоміжне з того самого часу: went → did, have seen → have, was → was.

✗ “I went to the concert.” “So do I.”

✓ “I went to the concert.” “So did I.”

Подвійне заперечення: Neither don’t I. Neither уже означає «теж ні», тому дієслово після нього стверджувальне: Neither do I, Neither can I. Neither don’t I, Neither can’t I неправильні.

✗ “I don’t like coffee.” “Neither don’t I.”

✓ “I don’t like coffee.” “Neither do I.”

Маркери: Yes, I do / No, I don’t, Yes, she is / No, she isn’t, So do I / So am I, So did I / So have I, Neither do I / Nor do I, Neither can I, Me too / Me neither, I think so / I don’t think so, I hope so / I hope not, I’m afraid so / I’m afraid not

Шпаргалка: яке допоміжне брати

Дивимося на перше речення. Якщо там є be, допоміжне або модальне (am, was, have, can, will, would), повторюємо його. Якщо там просто дієслово (like, plays, went), беремо do / does / did. Таблиця: що в першому реченні, «я теж», «я теж ні».

am / is / are · I’m cold. → So am I. · I’m not cold. → Neither am I.

was / were · I was late. → So was I. · I wasn’t late. → Neither was I.

дієслово в Present Simple · I like tea. → So do I. · I don’t like tea. → Neither do I.

he / she: дієслово з -s · Lily likes tea. → So does Max. · Lily doesn’t like tea. → Neither does Max.

дієслово в Past Simple · I lost my keys. → So did I. · I didn’t sleep. → Neither did I.

have / has + V3 · I’ve finished. → So have I. · I haven’t finished. → Neither have I.

can / could · I can ski. → So can I. · I can’t ski. → Neither can I.

will · I’ll come. → So will I. · I won’t come. → Neither will I.

would · I’d like some cake. → So would I. · I wouldn’t do that. → Neither would I.

Тренажер на 100 завдань: 5 раундів по 20. На уроці можна пройти 1-2 раунди, решту задати додому. Пояснення до кожної відповіді учень бачить у тренажері на сайті (розділ «Граматика»).
