1Теорія practiceteacher + student

Коли вживаємо

Нульовий тип: факти, закони природи, інструкції: If you freeze water, it turns into ice. (Якщо заморозити воду, вона перетворюється на лід.)

Нульовий тип: звички і те, що буває щоразу: If I go to bed late, I feel awful in the morning. (Якщо я лягаю пізно, вранці почуваюся жахливо.)

Перший тип: реальна умова в майбутньому: If it’s sunny on Saturday, we’ll go to the lake. (Якщо в суботу буде сонячно, ми поїдемо на озеро.)

Другий тип: уявна або малоймовірна ситуація зараз: If I had a horse, I would ride it to school. (Якби в мене був кінь, я б їздив на ньому до школи.)

Другий тип: порада з If I were you: If I were you, I’d call her. (На твоєму місці я б їй подзвонив.)

Форми

0 If + Present Simple, Present Simple. Приклад: If it’s cold, our cat sleeps on the radiator.

1 If + Present Simple, will + V. Приклад: If Emma calls, I’ll tell her the news.

2 If + Past Simple, would + V (could + V). Приклад: If we lived in Spain, we would eat dinner at ten.

− Заперечення: don’t / doesn’t у нульовому і першому, didn’t у другому; у головній частині won’t або wouldn’t. Приклад: If it doesn’t stop raining, we won’t go out.

? Питання ставимо в головній частині: What will you do if...? / What would you do if...?. Приклад: What would you do if you found a wallet?

, Кома: якщо if-частина перша, ставимо кому; якщо друга, кома не потрібна. Приклад: We’ll stay at home if the weather is bad.

Головна пастка

Ніякого will після if. Навіть коли йдеться про майбутнє, після if (when, as soon as, unless) стоїть Present Simple. Will живе тільки в головній частині.

✗ If you will come, we’ll play chess.

✓ If you come, we’ll play chess.

Ніякого would після if. У другому типі would тільки в головній частині, а після if стоїть Past Simple. Українське «якби я знав» не перекладаємо як If I would know.

✗ If I would know, I would tell you.

✓ If I knew, I would tell you.

Unless уже містить «не». Unless = if not («якщо не»). Тому після unless дієслово стверджувальне, інакше вийде подвійне заперечення.

✗ Unless you don’t call, I’ll worry.

✓ Unless you call, I’ll worry.

Маркери: if, when, whenever, unless, as soon as, If I were you, What will you do if...?, What would you do if...?, imagine, tomorrow / next week

Три типи в одній таблиці

Колонки: тип, if-частина, головна частина, значення. If I were you: сталий вираз для поради, тут завжди were. В інших реченнях другого типу з I / he / she / it можна і were, і was (were звучить формальніше). Unless = if not: Unless you hurry = If you don’t hurry. Після when, as soon as, before, after, until у реченнях про майбутнє теж без will.

0 · Present Simple · Present Simple · завжди правда: факт або звичка

1 · Present Simple · will + V · реально може статися в майбутньому

2 · Past Simple · would / could + V · уявне, малоймовірне або нереальне зараз

Тренажер на 100 завдань: 5 раундів по 20. На уроці можна пройти 1-2 раунди, решту задати додому. Пояснення до кожної відповіді учень бачить у тренажері на сайті (розділ «Граматика»).
